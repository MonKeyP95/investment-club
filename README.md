# investment-club
a club to help our investment group to become more professional, by learning basic to advance concepts of investing

## Structure

- `index.html` opens the current week's lesson; `lessons.html` lists all released lessons. Each lesson has four parts: Learn, Understand, Experiment, Think.
- `site-config.js`: set `currentWeek` to release a new week.
- `images/`: the shared logo image used in WhatsApp link previews.
- `whatsapp/`: Friday WhatsApp messages and admin-only answer keys. Not part of the website; copy and send by hand.
